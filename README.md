# 🏦 Bank Loan Analytics Dashboard

A comprehensive Business Intelligence dashboard built in Microsoft Power BI to evaluate loan portfolio performance, application metrics, funded amounts, and risk categorization.

## 🚀 Key Features & Functionality
* **Portfolio Overview:** Real-time tracking of total loan applications, funded amounts, total amount received, and average interest rates.
* **Good vs. Bad Loan Analysis:** Dynamic categorization segmenting performing loans from non-performing assets (NPAs).
* **Regional & Temporal Trends:** Visualizing loan issuance trends across months, states, and employee length categories.
* **Advanced DAX Measures:** Complex calculations for MTD/PMTD metrics, good loan percentages, and total funded vs received variances.

## 🛠️ Tech Stack & Tools
* **BI Tool:** Microsoft Power BI
* **Data Modeling & DAX:** Advanced measures, calculated columns, and financial KPI cards
* **Design & Layout:** Professional banking sector color theme and executive UI/UX standards
